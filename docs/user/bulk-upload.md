# Bulk upload of members

Use **Community → Bulk upload** to add many people at once, e.g. one batch from the school's register.

1. **Download the template.** It has one column per directory field (name, email, phone, batch…). Required columns are marked on the page.
2. **Fill it in Excel**, one person per row, and save it as **CSV UTF-8**. Columns can be in any order; extra columns are ignored.
3. **Upload and check the preview.** Each row shows:
   - **New**: will be added;
   - **Already exists**: matches someone in the directory (same email, phone, or batch and name);
   - **Duplicate in file**: the same person as an earlier row;
   - **Error**: something is missing or wrong; the reason is shown. Fix it in the file and upload again.
4. **Import.** For rows that already exist, choose to skip them or update the existing person with the new values (blank cells keep what's there).

The preview is kept for 30 minutes. Nothing is saved until you press Import.
